# 声波宇宙 · Sonic Universe

让音乐成为星空。一个在浏览器里运行的音乐视觉作品：低音推开星云，中频留下星轨，高音点亮星闪。在星环、银河、山峰与引力黑洞之间，看见一首歌的起伏。

**[进入在线体验](https://hgb-2005.github.io/sonic-universe/?v=32)** · **[完整使用说明](outputs/使用说明.md)** · **[有声黑洞示例](https://hgb-2005.github.io/sonic-universe/blackhole-demo.webm)**

## 第三十二版 · 稳定播放与时间点创作

- **画面有兜底**：启动超时、画布不可用或运行异常时显示轻量星光封面与跳动音频条，可播放示例并重试完整效果。
- **连接有结果**：Companion 检测最长 6.5 秒；离线时说明原因、禁用依赖在线服务的按钮，并提供重新连接。扫码有取消、超时和过期提示。
- **设备少吃力**：实际粒子数按设备上限创建；省电模式限制星尘、拖尾、分辨率并使用约 30 帧预览。后台暂停绘制；短片保持独立的导出质量。
- **一键套模板**：新增深空电影、金色柔光、省电星尘，连同原有八套预设共十一套，应用后可撤销、重做。
- **创作自动保存**：本机保存状态可见，失败可重试；关闭或切到后台前保存歌词、时间点与草稿。
- **拖动时间点**：点击轨道添加、拖动调整，方向键微调 0.1 秒（Shift 为 1 秒），支持文字、星爆、删除、撤销、重做，最多 60 个时间点。

## 第三十一版 · 会呼吸的歌曲封面与滚动歌词

这一版把正在播放的歌曲做成更有层次的界面。播放器封面扩大，增加唱片环、封面高光和随专辑图变化的模糊氛围光；歌曲标题下会显示歌手、专辑、来源和列表位置。没有封面或图片加载失败时，会回到当前主题的星云光晕，不影响播放。

歌词界面改成连续滚动舞台：当前句停在画面中央并放大发光，上一句和下一句向两侧渐隐；播放、暂停、自然切歌和拖动进度都会重新定位歌词，底部显示当前句数与总句数。歌词头部同步显示歌名、歌手和专辑，加载中、无歌词与解析失败都有对应提示。桌面、窄屏、低动态模式继续适配，本地音乐、汽水连接、星空、创作台、预设与短片导出功能保持不变。

## 第三十版 · 连接修复与旧版兼容

本机双击 **启动音乐入口.cmd** 后，可以在不下载歌曲文件的前提下搜索汽水音乐、扫码登录、读取收藏与个人歌单、显示歌词，并让能够公开播放的歌曲进入声波宇宙的播放队列。在线歌曲和本地歌曲都会驱动星环、银河、山巅与黑洞；上一首、下一首、暂停、进度和自然结束使用同一套播放逻辑。

- **完整在线入口**：本机 Companion 负责登录、搜索、收藏、歌单、歌词和临时音频代理；页面本身仍是同一个声波宇宙。
- **登录资料留在本机**：登录会话用当前电脑的本地密钥加密；Cookie、凭据和签名播放地址不会写入浏览器的音乐库、备份文件或 GitHub。
- **公开页面仍可独立使用**：`https://hgb-2005.github.io/sonic-universe/` 没有本机 Companion 时，四种星空、本地音乐、创作、明信片和短片照常工作；在线音乐区域会明确显示离线原因。
- **遵守平台边界**：作品不复制歌曲、不破解受保护音频，也不绕过会员、版权或 DRM。能内嵌播放的前提是服务能取得浏览器可用的普通音频；受保护歌曲会给出友好提示，并保留在汽水音乐中打开的入口。
- **可靠降级**：Companion 未安装、Node 版本不足或服务启动失败时，启动器会退回基础星空模式，不会留下黑屏。

## 第二十八版 · 汽水音乐歌单入口

这一版把作品从“只能播放本地文件”扩展成一条更轻量的音乐入口：在音乐库的「↗ 汽水音乐」中加入自己常听的歌，保存歌名、歌手、专辑或备注以及汽水音乐分享链接；点击歌曲会在新标签页打开汽水音乐。

- **单首与批量整理**：既可逐首填写，也可一次粘贴最多 100 行。支持 `歌名 | 歌手 | 专辑 | 链接`、全角竖线和制表符；每行必须带 `http://` 或 `https://` 分享链接。
- **自己的歌单**：汽水歌曲可以搜索、收藏、加入自定义歌单、排序、编辑和删除；刷新后仍保存在当前浏览器。
- **安全入口**：只接受不含账号密码的 HTTP(S) 地址，拒绝 `javascript:`、应用私链、畸形链接和重复链接。点击外链时以新标签页打开，并隔离页面来源。
- **声音驱动星空**：想用汽水音乐真正播放的声音改变星云时，在「外部联动」中选择「整个屏幕」并共享系统音频。选歌、切歌、暂停和音量仍在汽水音乐里操作。
- **本地与入口隔离**：汽水歌曲不会进入本地播放队列、随机播放、自动切歌或短片音频分析，也不要求音频文件。它们属于链接型音乐入口；内置音景与手动导入的本地歌曲仍按原流程播放。
- **隐私与备份**：页面只保存用户主动填写的元数据和分享链接，不下载、不复制音频，不读取汽水账号、会员状态、封面、歌词或播放进度。`.sonicpack` 备份会包含这些入口，但不会包含汽水音频。

本机地址与 GitHub Pages 属于不同网站来源，因此两边歌库分别保存。批量检查会先显示可加入、重复、无效和超过单次上限的数量，确认后才写入；已有链接和同一批中的重复链接都会被跳过。

## 第二十七版 · 从一首歌生成星空短片

现在可以不先选形态、不手动编排，直接选择一首本地歌曲。浏览器会在本机分析音乐能量，自动避开开头和结尾，推荐较完整的高潮片段，并把片段排成四章：

- **01 序曲 · 星光初醒**：星环随音乐缓慢展开。
- **02 漫游 · 旋律成河**：银河旋臂接住流动的旋律。
- **03 盛放 · 星河共鸣**：山巅声波抬高最明亮的部分。
- **04 余晖 · 光尘归寂**：引力黑洞收拢最后的余韵。

默认导出 720 × 1280 竖屏、30 秒短片，录制时音乐与画面同步进入文件。推荐起点可以手动修改，15 / 30 秒会重新计算四章时间线；录完可在页面预览并下载。音频分析、歌曲文件和短片都在本机处理，不会上传到服务器。

## 第二十三版 · 星云回流

这一版处理首页下半屏的大片空白：主画面略微下移并纵向延展，下方增加一层由同一星云材质裁切、重组的缓慢回流。回流保留暗尘裂缝、不均匀密度和断续亮脊，边缘向左右柔和消散，并加入少量星点与鼠标微动，让首屏到播放器之间形成连续的星云电流。

四套形态各自保留原有主体结构，紫色、蓝色和金色主题仍共用同一套材质，只改变颜色。静默时回流结构完整，播放后只增强亮度、呼吸和局部星芒；控制面板与播放器文字保持清晰。本版曾在桌面顶部、滚动区域和 390 × 844 移动视口检查四形态、三主题、衔接边缘、横向溢出与加载错误。

## 第十九版 · 让四种形态一起流动

星环、银河、山峰与引力黑洞现在共用一套流体星云语言：软圆光斑、分层辉光、持续噪声扰动和渐变衰减拖尾。没有音乐输入时，画面仍会缓慢呼吸；播放后用低频推动星云与黑洞光晕，中频改变旋转和山峦起伏，高频触发细碎星闪。

- **星环与银河**：环体与旋臂会自然弯曲、疏密变化，粒子沿切线留下光轨；银河粒子持续向中心缓慢旋入。
- **山巅声波与黑洞**：频谱化作多层半透明雾状山脊；黑洞拥有不透明深黑视界、流体吸积盘、内外层差速和星尘吞噬循环。
- **新的画面控制**：新增 0–100%「拖尾长度」和可选「节拍触发」，柔和／均衡／强烈三档映射统一适配四种形态。节拍触发默认关闭，开启后只在真实强鼓点出现时增加星爆与光晕脉冲。
- **统一转场与静默流动**：切换形态时，新旧星云约在半秒到一秒内交叠淡入淡出；暂停或静音后保留较慢的环境流动。
- **设备分级与容错**：桌面、平衡与移动端会分别限制粒子数量和拖尾强度；WebGL／Canvas、音频上下文异常时会显示说明与重启入口，不再只剩黑屏。
- **分享与预设**：八套内置预设都记录拖尾、响应和节拍设置。分享链接编码形态、色彩、拖尾、强度、粒子数、响应和速度，不包含歌曲、歌词或个人信息。

本版使用真实浏览器自动化检查四种形态和连续转场、黑洞不透明视界、0% 与 100% 拖尾差异、节拍开关、主页面／创作台／沉浸面板同步、分享恢复、刷新持久化、桌面与 390px 移动端性能分级及剪贴板拒绝后的只读链接回退。

## 在星空里听见此刻

沉浸时，点右上角「选星空」，可以在深空电影、金色柔光、省电星尘等十一套氛围之间切换，也可以直接选择四种宇宙形态。画面缓缓相融，音乐保持当前进度。面板内能选择柔和、均衡、强烈的光响应，并调整拖尾与节拍触发；这些设置与主面板、创作台共用并保存在当前浏览器中。

轻触星空唤醒控制栏，明确拖动才接管视角，手机支持双指缩放。面板打开或键盘正在操作按钮时保持控制栏可见；关闭按钮和 Esc 可收起选景面板。浏览器也可能使用 Esc 退出原生全屏，此时返回主空间。

内置原创音景优先加载预先生成的 96 秒 MP3，减少刷新后的合成等待；资源无法读取或解码时自动回到原有合成，准备期间会显示提示。导入自己的音乐仍直接在本机播放。

低音继续控制星云的扩张与呼吸，200 Hz–4 kHz 的中频频谱留下短暂星轨，高音的变化唤起局部细碎星闪。轻声、停顿和暂停后自然收静；星轨记录近期频谱，不进行音符或音高识别。

主页面围绕播放、沉浸、定格和导出展开。原有星际航行收在页脚「星际航行小实验」中，作为可选入口。

新增图层共享主画布、乐器预览与短片输出，也支持 Canvas 兼容模式和系统减少动态效果。短片优先使用 VP8 编码，改善连续切换横竖画幅的录制启动。

## 从一首歌开始

1. 打开在线体验，点击播放，先听内置原创音景；也可以上传自己的 MP3、WAV 等浏览器支持的音频。
2. 打开「视觉预设」，试试「紫雾星环」「日冕引力」或「紫晶旋臂」，再调节拖尾长度；数字键 1 / 2 / 3 / 4 可切换四种形态。
3. 点击「进入宇宙」沉浸漫游，通过「选星空」边听边选景。轻触唤醒按钮，拖动旋转、滚轮或双指缩放，右上角返回空间。
4. 保存自己的视觉预设、定格星空明信片，或录制带声音的横屏／竖屏短片。

## 可以在这里创作什么

- **音乐星空**：Web Audio 分析声音，以 Canvas 流体粒子绘制四种星云，并保留 GPU／Canvas 兼容路径；支持连续转场、响应校准、拖尾、节拍触发、空间纵深与光晕。
- **自己的音乐空间**：音乐库、歌单、封面和背景；歌词编辑、歌曲草稿、收藏、A/B 排练与时间点编排。
- **汽水音乐入口**：在本机 Companion 模式下搜索、扫码登录、收藏、读取歌单与歌词；可公开播放的歌曲直接驱动星空，受保护歌曲仍可在汽水音乐中打开。
- **视觉收藏**：八种内置预设，自定义预设保存、JSON 导入／导出，以及创作撤销与重做。
- **星际乐器台**：鼠标、触屏或键盘弹奏旋律与鼓点，录制循环并叠加最多六层。
- **带声音的作品输出**：星空明信片、横屏和竖屏视频；WebGL 图层、歌词与乐器画面共用输出链路。
- **外部声音联动**：在支持的桌面浏览器中，经用户选择和授权，分析带音频的共享来源。

## 本地运行

Windows 用户安装 Node.js 24 或更高版本后，双击 **启动音乐入口.cmd** 即可运行完整在线入口。首次启动如果缺少 `companion` 依赖，会在本机安装；启动器只监听 `127.0.0.1:8765`，随后打开 `http://127.0.0.1:8765/?v=32`。**打开声波宇宙.cmd** 使用同一套逻辑。Node 不可用时，启动器会尝试用 Python 3 打开不带在线音乐的基础版本。

macOS、Linux 或希望手动运行完整入口时，在仓库根目录执行：

```sh
cd companion
npm ci
npm start
```

随后打开 `http://127.0.0.1:8765/`。Companion 同时提供网页和本机音乐接口，仅接受来自这个本机地址的请求。建议通过 HTTP 或 HTTPS 使用作品，以便浏览器完整提供音频和存储能力。

## 浏览器与数据

推荐使用桌面版 Edge 或 Chrome。手机支持触屏界面；共享声音、录制编码、全屏及可解码格式取决于浏览器和设备。共享声音需要在浏览器弹窗中选择带音轨的来源并启用音频共享，不能保证所有系统播放器都可捕获。视频采用实时录制，建议让页面保持在前台。

导入的音乐、图片、歌词、草稿和在线歌曲元数据保存在当前浏览器中，应用不会把这些内容上传到 GitHub。完整的汽水音乐在线功能只在本机 Companion 运行时可用；登录 Cookie、账号凭据和临时播放地址只留在 Companion 内存或加密的本地会话文件中。`127.0.0.1` 与 GitHub Pages 属于不同网站来源，两边歌库和草稿不会自动互通；不同浏览器也各自保存。可通过 `.sonicpack` 完整备份迁移，视觉预设也可单独导出 JSON。备份仅包含在线歌曲的公开元数据，不包含登录凭据、Cookie 或签名播放地址。

## 源码与部署

`outputs/index.html` 包含界面、Web Audio、Canvas 流体渲染与兼容绘制；`outputs/visual-system.js` 负责软粒子、噪声、拖尾、性能分级和分享参数，`outputs/visual-presets.js` 提供十一套内置预设，`outputs/music-motion.js` 处理三层声音包络与近期频谱，`outputs/online-music.js` 规范在线歌曲、歌词与 Companion 请求，`outputs/soda-library.js` 校验旧版汽水分享链接。`companion/` 包含仅监听本机的 Node 服务、汽水音乐适配器和加密会话存储。`outputs/interstellar-drift.mp3` 由内置合成算法预先生成，作品继续保留同一算法作为加载失败时的回退。

航行模式由 `flight.html`、`flight.css`、`flight.js` 和 `flight-core.js` 组成，不加载外部依赖。关卡与计分核心独立于帧率，使用 Web Audio 时钟对齐音乐与事件。它与原音乐星空共享网站地址，各自保存音乐资料和航行成绩。

安装 Node.js 24 后在 `companion/` 执行 `npm ci`，再回到仓库根目录运行 `node --test tests/*.test.cjs`。测试覆盖音乐短片、视觉参数、在线歌曲与歌词、Companion 接口、凭据隔离、作品备份、可选航行和既有视听逻辑。GitHub Pages 部署前还会安装 Companion 依赖、检查全部运行脚本语法并执行同一套测试。

GitHub Actions 将 `outputs/` 发布到 GitHub Pages；推送到 `main` 的作品更新会自动部署。仓库不包含本机音乐库、调试日志、历史截图或测试音轨。
