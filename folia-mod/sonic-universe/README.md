# 声波宇宙 · Sonic Universe for Folia

把 Folia 正在播放的音乐变成星空。这是一个纯客户端的 Folium 1.8 背景模组，不读取歌词内容，不上传音频，也不需要任何权限。

**[下载 Folia 版 sonic-universe-folia-1.1.0.zip](https://github.com/Hgb-2005/sonic-universe/releases/latest/download/sonic-universe-folia-1.1.0.zip)**

## 功能

- **星环**：气态环体带有暗尘切缝、断续亮脊和不均匀的云缘。
- **银河**：旋臂由细密星云、暗带与散星共同组成，中心保留清晰亮核。
- **山巅声波**：多个景深中的流体山脊叠成雾状轮廓，不再绘制硬网格。
- **引力黑洞**：破碎、湍动的吸积流围绕不透明事件视界，保留内外层差速。
- **共用结构**：紫色、蓝色与金色主题只调整一套云体的颜色、亮度与明暗关系，不更换造型。
- **自动轮换**：约每 36 秒平滑切换下一幕，也可在设置中固定场景。

主画面以体积星云为主体，粒子只作稀疏远景星点。宿主的低频推动整体亮度和轻微呼吸，中频只改变很小的尺度与旋转，高频在已有亮脊上触发克制闪光。没有分析器、歌曲静音或播放暂停时，声音响应会自然收静，不会把静默星云拉成线条。系统开启“减少动态效果”后，运动会自动放缓。

## 安装

1. 从上方链接下载 `sonic-universe-folia-1.1.0.zip`。
2. 打开 Folia 的「设置 → 模组」，把 ZIP 拖入安装区，或选择从文件安装。
3. 启用「声波宇宙」。
4. 在背景选择器中选中「声波宇宙」，然后在模组设置里选择场景、调整星尘密度与声音响应。

也可以把解压后的 `sonic-universe` 文件夹放进 Folia 的模组目录，再重新载入模组。

安装页显示“未验证”是正常状态：这个版本没有使用 Folium 官方签名，并不表示官方检查失败。发布前已通过 Folia 仓库提供的 `dev/folium/check.mjs` 静态检查。

## 隐私与权限

- 权限清单为空：`permissions: []`。
- 不读取歌词、歌曲信息、文件名或音频样本内容。
- 不上传音频，也不发起网络请求。
- 只在 Folia 提供的播放状态与频段数据上绘制；暂停、静音或没有分析器时自然收静。
- 不包含主进程代码、远程脚本、第三方运行时或额外依赖。

## 兼容

- Folium API：1
- Folia：1.8 的公开背景 API
- 渲染：Canvas 2D，无需 WebGL、网络请求或主进程代码
- 宿主能力：播放页与背景预览；OBS、透明表面和视频／图片导出是否绘制背景由 Folia 宿主决定

高 DPI 渲染在两倍以内设上限；持续高帧耗时会逐步降低粒子绘制量。OBS 与透明导出由 Folia 宿主决定是否绘制背景，模组不会覆盖宿主的透明表面规则。

## 文件

- `client.mjs`：向 Folium 注册一个背景条目并管理挂载生命周期。
- `src/renderer.mjs`：四种场景、自动轮换、平滑转场和画布生命周期。
- `src/nebula.mjs`：读取并共用四套体积星云结构，按宿主主题重新着色；加载失败时使用断续亮脊兜底。
- `src/nebula-assets.mjs`：以 Data URL 内嵌四张透明 WebP 星云纹理，运行时不发起网络请求。
- `src/analysis.mjs`：音频平滑、频谱分带和静音收束。
- `src/palette.mjs`：跟随 Folia 主题色生成星空配色。
- `preview.html`：本地开发预览页，不属于宿主运行必需功能。
