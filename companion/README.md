# 声波宇宙 · 本机音乐入口

这个 Node.js 小服务提供汽水音乐的搜索和现有账号功能，以及网易云音乐、QQ 音乐的歌曲搜索与官方页面跳转。它同时提供 `outputs/` 中的网页，双击仓库根目录的 **启动音乐入口.cmd** 即可启动。更新项目后再次运行启动器，可更新本项目的旧音乐入口。

网易云和 QQ 的搜索基于非正式公开接口，平台变更、网络或地区限制可能导致不可用；这两家暂不支持账号登录、导入云歌单、站内播放或同步歌词。可在官方播放器播放，再使用「外部联动」共享声音驱动星空；浏览器与操作系统须支持音频共享。

## 运行要求

- Node.js 24 或更高版本。
- 首次安装依赖时需要网络。
- Windows 启动器会优先启动本服务；找不到 Node、依赖安装失败或端口被其他程序占用时，会尝试退回只展示网页的 Python 基础模式。

手动运行：

```sh
cd companion
npm ci
npm start
```

然后打开 `http://127.0.0.1:8765/?v=33`。运行 `npm run check` 检查服务语法，运行 `npm test` 检查 Companion 与浏览器端在线歌曲逻辑。

## 隐私与边界

- 服务只监听 `127.0.0.1`，拒绝其他 Host 和不允许的浏览器来源。
- 登录会话保存在 `%LOCALAPPDATA%\SonicUniverse`，用当前电脑生成的 AES-256-GCM 密钥加密。
- Cookie、账号凭据和汽水签名播放地址不写入网页音乐库或 `.sonicpack` 备份。
- 临时媒体地址保存在内存中，网页拿到的只是随机短期 `/media/...` 路径；过期后不能继续使用。
- 服务不复制歌曲文件，不破解受保护音频，也不绕过会员、版权或 DRM。
- 只能内嵌播放服务明确提供、且浏览器可访问的普通音频；受保护歌曲会返回友好错误，用户仍可从网页打开汽水音乐。

公开 GitHub Pages 没有这个本机服务时，星空、本地音乐、创作和短片功能仍正常工作，在线音乐区域会显示离线说明。
